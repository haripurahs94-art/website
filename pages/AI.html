AI-এর মাধ্যমে Web Development শুরু করার প্রাথমিক Software ও Tools

Web Development শেখা ও প্রজেক্ট তৈরি শুরু করতে নিচের Software ও অনলাইন সেবাগুলো প্রয়োজন হবে।

১
Visual Studio Code (VS Code)

Code লেখার জন্য এটি প্রধান Code Editor। HTML, CSS, JavaScript, TypeScript এবং বিভিন্ন Web Development Project তৈরিতে VS Code ব্যবহার করা হবে।

২
Node.js (LTS Version)

JavaScript ও TypeScript এবং বিভিন্ন Web Development Tool চালানোর জন্য Node.js একটি প্রয়োজনীয় Runtime Environment।

Node.js-এর সঙ্গে npm পাওয়া যায়। npm ব্যবহার করে বিভিন্ন Package ও Development Tool ইনস্টল এবং পরিচালনা করা যায়।

৩
Git Bash

Git Version Control এবং বিভিন্ন Development Command চালানোর জন্য Git Bash একটি Terminal Environment। এর মাধ্যমে Git, Node.js/npm এবং Web Development-এর অন্যান্য Command ব্যবহার করা যাবে।

Windows-এর জন্য Git ডাউনলোড ও ইনস্টল করুন

৪
GitHub Account

Code সংরক্ষণ, Project Management এবং Team-এর সঙ্গে কাজ করার জন্য GitHub ব্যবহার করা হয়। Git Bash-এর মাধ্যমে Local Computer-এর Project GitHub-এ Push, Pull ও Manage করা যাবে।

GitHub-এ Account তৈরি করুন বা Sign in করুন

VS Code-এ HTML ফাইলে প্রাথমিক কোড আনা

নতুন HTML ফাইল তৈরি করে Emmet-এর ! abbreviation ব্যবহার করে প্রয়োজনীয় HTML কাঠামো স্বয়ংক্রিয়ভাবে যোগ করুন।

১

Visual Studio Code (VS Code) খুলুন।

২

মেনু থেকে File > New File নির্বাচন করুন।

৩

ফাইলের নাম লিখুন, যেমন wohab.html, তারপর কিবোর্ডে Enter চাপুন।

৪

ফাইলটি কোথায় রাখবেন সেই ফোল্ডার নির্বাচন করে Create File বা Save নির্বাচন করুন।

৫

নতুন HTML ফাইলে ক্লিক করে কিবোর্ড থেকে Shift + 1 চাপুন; এতে ! টাইপ হবে।

৬

Emmet-এর পরামর্শ থেকে ! নির্বাচন করে Enter চাপুন। এতে HTML-এর প্রাথমিক কাঠামো স্বয়ংক্রিয়ভাবে ফাইলে যুক্ত হবে।

AI-এর মাধ্যমে HTML ফাইল এডিট করার নিয়ম

VS Code-এ GitHub Copilot Chat ব্যবহার করে HTML ফাইলের তথ্য বা কোড পরিবর্তন করতে নিচের ধাপগুলো অনুসরণ করুন।

১

Visual Studio Code (VS Code) খুলুন।

২

মেনু থেকে File > Open Folder... নির্বাচন করুন।

৩

যে ফোল্ডারের ফাইল AI-এর মাধ্যমে এডিট করতে চান, সেটি নির্বাচন করে খুলুন। ফোল্ডারের ফাইলগুলো Explorer-এ দেখা যাবে।

৪

যে HTML ফাইলের তথ্য বা কোড পরিবর্তন করতে চান, সেটি খুলুন।

৫

প্রয়োজনে VS Code-এ GitHub Account দিয়ে Sign in করুন।

৬

ডান পাশের Chat প্যানেল খুলে Chat with Copilot বক্সে কী পরিবর্তন চান তা স্পষ্টভাবে লিখে পাঠান।

৭

Copilot-এর প্রস্তাবিত পরিবর্তনগুলো দেখে যাচাই করুন এবং প্রয়োজন অনুযায়ী গ্রহণ বা সংশোধন করুন।

AI-এর মাধ্যমে Folder-এর HTML ফাইল এডিট করার শর্টকাট নিয়ম

VS Code-এর ভেতর থেকে Folder না খুলে সরাসরি Folder-এর মেনু থেকে VS Code-এ খোলার সহজ পদ্ধতি নিচে দেওয়া হলো।

১

যে Folder-এর HTML ফাইল AI-এর মাধ্যমে এডিট করতে চান, সেই Folder-এর উপর মাউসের কার্সর রাখুন।

২

মাউসের ডান বাটনে ক্লিক করুন।

৩

মেনু থেকে Open with Code নির্বাচন করুন। এই অপশনের আগে VS Code Editor-এর চিহ্ন (আইকন) থাকবে।

৪

Folder-টি VS Code-এ খুলে যাবে। Explorer থেকে যে HTML ফাইল পরিবর্তন করতে চান সেটি খুলুন।

৫

এরপর ডান পাশের Chat প্যানেলে Copilot-কে কী পরিবর্তন চান তা লিখে পাঠান।

HTML-এর <img> ট্যাগ

ওয়েবপেজে ছবি দেখানোর সহজ উপায় 🖼️

মূল কথা

<img> দিয়ে ওয়েবপেজে ছবি দেখানো হয়। এটি খালি ট্যাগ, ক্লোজিং ট্যাগ লাগে না।

<img src="photo.jpg" alt="ছবির বর্ণনা" width="600" height="400">

৪টি জরুরি অ্যাট্রিবিউট

  • src : ছবির ঠিকানা (আবশ্যক)
  • alt : ছবির বর্ণনা, ছবি লোড না হলে এটি দেখায় (আবশ্যক)
  • width, height : মাপ দিলে পেজ লাফায় না
  • loading="lazy" : দরকার হলেই ছবি লোড হয়, পেজ দ্রুত খোলে

ছবি রেসপনসিভ করতে CSS-এ দিন: max-width:100%; height:auto;

HTML-এর <a> (অ্যাঙ্কর) ট্যাগ

লিংক তৈরির ট্যাগ 🔗

মূল কথা

<a> (অ্যাঙ্কর) ট্যাগ দিয়ে লিংক তৈরি হয়। লিংকে ক্লিক করলে অন্য পেজ, ফাইল বা পেজের অন্য অংশে যাওয়া যায়।

<a href="https://example.com" target="_blank" rel="noopener">এখানে ক্লিক করুন</a>

জরুরি অ্যাট্রিবিউট

  • href : লিংকের গন্তব্য (আবশ্যক)
  • target="_blank" : নতুন ট্যাবে খোলে
  • rel="noopener" : নতুন ট্যাবে খুললে নিরাপত্তার জন্য দিন
  • download : ক্লিকে ফাইল ডাউনলোড হয়

href-এ কী কী দেওয়া যায়

  • ওয়েব ঠিকানা: https://example.com
  • পেজের অংশ: #contact
  • ইমেইল: mailto:name@mail.com
  • ফোন: tel:+8801700000000
